# TrailHome — путь домой для грибника / offline-friendly forest navigator (Android, Kotlin)

Голосовой компас и карта: помогает вернуться к отмеченной точке из незнакомого места.

## Возможности
- Цель — любая метка; при нажатии «Старт» создаётся метка «Старт №N …» и становится целью.
- Карта OpenStreetMap (osmdroid): тап или долгий тап создаёт метку в любой точке, трек и метки на карте, нажатие на метку открывает её.
- Радар и направление «по часам», голосовые подсказки, работа в фоне (foreground-сервис).
- Метки: переименование, заметки, ручной ввод координат (подставляются текущие), поиск, экспорт и импорт GPX.
- Голосовой ввод во всех полях: название заменяется, заметка дополняется.
- Трек за час, сутки и всё время с разбивкой по периодам.
- Настройки: язык (системный, English, Русский), тема (системная, светлая, тёмная), инструкция.

## Сборка
Откройте папку в Android Studio (JDK 17), дождитесь синхронизации Gradle и запустите на устройстве (Android 8.0+).

## Карта без интернета
Тайлы сохраняются в кэш по мере просмотра (до ~1 ГБ). Заранее просмотрите нужный район дома по Wi-Fi.
Полноценное скачивание областей одной кнопкой пока не реализовано.
